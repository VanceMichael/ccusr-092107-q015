# 平陆运河双线巡航处置闭环

把**电子巡查组（线上智慧感知）**的风险结论与**水上巡查组（线下登临）**的现场
处置接成同一条只进的处置链：智慧感知 → 远程核验 → 预警推送 → 船舶叫应 →
巡查艇任务 → 登临检查 → 复查 → 闭环；误报在派单前可撤销。

## 解决的核心问题

- **两套系统船舶标识不一致**：雷达航迹号、AIS 的 MMSI、视频识别船牌异构。
  身份归并（`src/identity.py`）对每一次归并都留下可解释决策
  （依据规则、作证观测、时间差与距离），值班员可逐条回溯，不靠黑箱匹配。
- **传感器迟到/补报**：报文同时记录观测时间 `obs_ts` 与到达时间 `arrival`。
  迟到数据可以补做身份归并、作为证据附挂，但**绝不倒退已经人工确认的状态**；
  案件终态（闭环/撤销）后到达的反证或新风险进入隔离复核队列。
- **现场任务重复或漏掉**：同一身份簇只对应一个在办案件；传感器重复报文去重；
  断网期间的现场操作按 `client_id` 幂等补传，重放不会产生第二条登临记录。
- **人员、巡查艇、锚地泊位冲突**：调度器（`src/resources.py`）在派单时
  协调艇与执法人员，泊位被占则同锚地改派，本航段无艇则按最近邻段跨航段支援；
  登临完成释放艇与人员，泊位保留到案件关闭/撤销。
- **值班视图与溯源**：值班员可看到全部未闭环风险及其当前待办；任一现场结果
  都能沿溯源链反查最初的雷达、视频、AIS 或水文气象依据。

## 处置状态机（`src/case.py`）

```
DETECTED ──人工确认──▶ CONFIRMED ──推送──▶ PUSHED ──叫应──▶ CALLED
   │                     └──────── 误报撤销（派单前）────────▶ REVOKED
   ▼
DISPATCHED ──登临──▶ BOARDED ──复查合格──▶ CLOSED
```

- 状态只能由人工命令推进；自动感知数据只累积证据。
- 违规案件（登临结论 `violation`）必须复查合格才允许闭环（`src/service.py`）。
- `CLOSED` / `REVOKED` 为终态，拒绝一切新命令；迟到数据只附挂或隔离。

## 模块

| 文件 | 职责 |
| --- | --- |
| `src/model.py` | 航段、限制区、锚地泊位、设备、船舶、巡查艇与人员的世界模型 |
| `src/identity.py` | 多源身份归并台账：登记匹配、时空关联、补报回溯，全部可解释 |
| `src/evidence.py` | 观测证据池与风险规则（超速、闯入限制区、雾航、低富余水深） |
| `src/case.py` | 事件溯源案件状态机、终态屏障、断网命令幂等 |
| `src/resources.py` | 巡查艇/执法人员/锚地泊位的时空冲突调度 |
| `src/gateway.py` | 报文去重、断网本地队列、恢复补传与重传幂等 |
| `src/service.py` | 编排全闭环；值班看板 `open_risk_board()` 与溯源 `lineage()` |
| `src/loader.py` | 读取 fixtures 构建世界模型 |
| `src/scenario.py` | 驱动样例事件流（含断网/补传/乱序到达） |
| `src/report.py` | 打印可读处置报告 |

## 资料（编号与主体均为虚构）

- `fixtures/segments.json`：马道/青年/企石三航段、限速、施工限制区与锚地泊位
- `fixtures/devices.json`：雷达、视频、AIS 基站、能见度仪、水文站、气象站
- `fixtures/vessels.json`：船舶登记（MMSI、船牌、吃水、最小富余水深）
- `fixtures/resources.json`：巡查艇与执法人员
- `fixtures/events.json`：四个相互交织的样例场景
  - **A 马道雾航**：雷达/视频/AIS 三源归并 → 登临复查闭环 → 闭环后补报不倒退
  - **B 青年超速**：雷达先建单，迟到 AIS 补报归并，不开第二单
  - **C 企石水位陡涨**：双船低富余水深、泊位改派、跨航段支援、断网补传去重
  - **D 青年误报**：推送后视频复核撤销，迟到 AIS 报文不翻案

## 本地校验

```bash
python -m unittest discover -s tests   # 39 个用例
python -m src.report                   # 打印四个场景的处置链、身份解释与溯源
```

样例中的编号均为虚构值，不含账号、凭据或真实主体信息。
