# 运河双线巡航闭环

连接智慧感知告警、电子核查、水上巡查和复查结果。

## 领域资料

`contracts/context.schema.json` 约定基础资料格式，`fixtures/context.json` 提供不含真实个人信息的示例。代码模块只负责读取和校验这些资料，后续业务服务可以沿用其中的领域标识与版本约定。

当前资料记录了以下业务事实：

- 巡航采用线上智慧感知与线下实地核查两个工作组
- 系统汇聚船舶、船员、航道和水文气象等多源数据
- 处置流程强调预警推送、船舶叫应和现场核查

## 本地校验

运行项目自带测试可确认示例资料能够读取，且领域标识、版本和事实列表完整。示例中的编号均为虚构值，不包含账号、凭据或真实主体信息。
